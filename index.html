Smart Trash Can — PFA · ISIMM

Système de tri automatique des déchets basé sur ESP32 et IA

ESP32 · Capteurs ultrasoniques · TensorFlow & Python · Base de données · Application web (Flask)

Conception d’une poubelle intelligente capable de détecter le niveau de remplissage et de classifier les déchets à l’aide d’un modèle d’intelligence artificielle, avec suivi en temps réel via une plateforme web.

  • Programmation de l’ESP32 et intégration des capteurs ultrasoniques pour la collecte de données en temps réel.
  • Entraînement et intégration d’un modèle TensorFlow en Python pour la classification des déchets.
  • Connexion à une base de données et développement d’une application web pour le suivi et l’affichage dynamique.
Projet personnel

Assistant de portefeuille personnel (n8n + IA + Telegram)

n8n · IA · Telegram Bot · Google Sheets · APIs · Automatisation de flux

Mise en place d’un assistant automatisé capable de suivre un portefeuille personnel, d’analyser des données financières et de fournir des recommandations enrichies avec des informations contextuelles (dont la météo).

  • Création de workflows n8n connectés à Telegram et Google Sheets pour centraliser les données.
  • Automatisation de l’analyse financière et génération de conseils personnalisés.
  • Intégration d’APIs (dont météo) pour enrichir les scénarios et adapter les recommandations.
Projet IoT

Interface web connectée à des capteurs IoT

IoT · Web front‑end · Base de données · Visualisation temps réel

Développement d’une interface web permettant de visualiser en temps réel les données issues de capteurs IoT connectés, avec stockage dans une base de données et affichage dynamique.

  • Conception de la structure de la base de données pour les mesures IoT.
  • Intégration de la collecte de données depuis des cartes type Arduino / ESP32.
  • Développement de l’interface web pour l’affichage en temps réel des valeurs et des courbes.
